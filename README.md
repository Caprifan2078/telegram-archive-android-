# Telegram Archive Viewer

Android-приложение для локального просмотра экспортированных архивов Telegram: переписки, поиск, статистика, медиа, локальные заметки, резервные копии и учебный режим.

## Текущий статус

Основная ветка `main` сохраняет базовую кодовую линию **QA 0.47 Reliability UX**. В рабочей ветке `qa/v052-duplicate-id-safety-20261026` интегрированы экспериментальные улучшения версии **0.51**: локальный поиск, разбор ответов, исправления конфликтующих Telegram-ID и потоковый импорт HTML. Для Android-проекта в Gradle по-прежнему указано `0.51`; название рабочей ветки **не является номером готового релиза**. Полная сборка и Android-инструментальные испытания этих изменений не подтверждены. Подробности и незакрытые риски — в [техническом статусе](docs/STATUS_RU.md).

## Приватность

- В репозитории должны находиться только исходники, тесты и вымышленные учебные материалы.
- Не добавлять реальные Telegram-переписки, пользовательские записи экрана, фотографии, аудио, архивы, пароли, токены, приватные ключи и персональные логи.
- Изображения и учебные медиа не предназначены для демонстрации реальных пользовательских данных.
- Перед любым новым коммитом проверять diff, ресурсы и метаданные.

## Разработка

- Основная ветка: `main`. Изменения проверять в отдельной QA-ветке.
- Не объявлять неподтверждённые тесты успешными; исправлять проблемы сборки и проверять пользовательские данные на тестовых локальных архивах.
- Не копировать исторические Git-коммиты из других проектов или репозиториев.
- Для CI применять минимальные разрешения, стандартные GitHub-hosted runners и синтетические тестовые материалы.
