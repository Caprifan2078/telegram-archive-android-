## Независимый Android QA

Включены UI проверки семи пояснений, истинные количества на тепловой карте, основные медиа, поиск, импорт и reply-to. Это **до** последней синхронизации верхнего заголовка.

- [Повторный базовый emulator QA после исправления заголовка](https://github.com/Caprifan2078/telegram-archive-android-/actions/runs/40402873965) **ещё требует окончательного результата**. Он включает обязательный экспорт синтетического PNG-скриншота; не путать факт генерации с визуальной приёмкой.

## Осталось проверить самому, до передачи пользователю

1. Анализ на узком экране с большим шрифтом: 24 часа, 12 месяцев, 7×6 клеток, две серии А/Б; текст и оси не должны обрезаться.
2. Сворачивание и возвращение в приложение во время видео и TGS/GIF; плавающий кружок при прокрутке настоящего длинного чата.
3. Сохранение данных при обновлении APK. Текущие тестовые APK **не гарантируют бесшовное обновление** из-за непостоянного debug keystore в публичном GitHub CI. Не распространять следующую QA как Stable.
4. Разные реальные форматы экспортов, большие части HTML, медиа GB+ и разные SAF providers; синтетические тесты не заменяют их.
5. Все скриншоты реальных переписок и видео из пользовательского архива должны оставаться приватными. В GitHub — только синтетические данные.

**Важно:** пользователь не должен устанавливать очередную APK после каждого исправления. Ручная приёмка на телефоне будет позже, когда автоматический минимум и signing upgrade защищены.
