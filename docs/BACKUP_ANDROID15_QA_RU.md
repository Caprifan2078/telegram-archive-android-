# QA: резервное копирование на Android 15

## BACKUP-15 (P0): ложный отказ восстановления

Коммит 73d3aed: [общий Android 15 прогон](https://github.com/Caprifan2078/telegram-archive-android-/actions/runs/40482486471) обнаружил два отказа тестов восстановления: резервная копия отклонена как повреждённая. Лог SQLite показывает попытку команды FTS integrity-check записать в базу, открытую только для чтения. Это указывает на возможную причину; необходимо проверить исправление на эмуляторе.

Экспериментальная правка: quick_check выполняется на отдельной временной копии проверенной базы с правом записи; исходный проверенный файл остаётся неизменным и используется при восстановлении. Добавлены тесты FTS, целостности исходных байтов, удаления временных файлов и отказа повреждённой базы; существующие тесты полного восстановления и переноса заметок запускаются на API 30, 34 и 35. Проверка потребует дополнительное свободное место размером до одной базы. Состояние: **не проверено, нельзя считать исправленным до завершения прогонов**.
