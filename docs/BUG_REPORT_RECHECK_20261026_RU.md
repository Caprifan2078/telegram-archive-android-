### Визуальные скриншоты и видео

- Шесть старых снимков действительно показывают: отсутствующие точные числа в столбцах, обрезанные подписи типа `09.2`, отсутствие некоторых почасовых подписей, двусмысленную шкалу 0–10, обрезаемую сетку года и неочевидные серии А/Б.
- Три старых видео просмотрены выборочно по кадрам: навигация/настройки, учебная переписка с медиа и полный/встроенный медиаплееры. Это **историческая визуальная проверка, не новый Android regression**. Нельзя оценить звук/FPS по пережатым видео без звука.
- Текущий аналитический код изменён и частично проверен на synthetic UI; нет набора сопоставимых скриншотов новой APK с разными ширинами/fontScale. Не закрывать визуальные жалобы преждевременно.

## P0 — реальный риск обновления 0.51 (B21)

Сравнивались два разных GitHub-generated `app-compactQa.apk`, одинаковый
`applicationId=org.openarchive.telegram.qa.preview51`. Сертификаты
из APK Signature Scheme v2 извлечены локально, fingerprint SHA-256:

- [Более ранняя успешная сборка](https://github.com/Caprifan2078/telegram-archive-android-/actions/runs/40395592267):
  `51c908ad8fe4f3c969716a9e0d611bb20406dc56b746247766f2d393c9e2d0bc`
- [Сборка с исправлением ползунка](https://github.com/Caprifan2078/telegram-archive-android-/actions/runs/40396573293):
  `52e28cb44488efa2dad5b944dc76cb4624514fa1d40672aaf55f4689e41b52e5`

Сертификаты **различаются**. APK версии 0.51 может быть установлена рядом
с 0.50 (разные package ID), но две 0.51 APK с разной подписью не обновят
друг друга поверх прежней установки. Удаление приложения может удалить
его локальную базу/настройки. **Не удалять/переустанавливать с данными ради
обновления.** Тестовый debug-key нельзя выкладывать в Public репозиторий.
Необходимо настроить постоянный приватный QA keystore через GitHub Secrets
и проверить clean install + in-place upgrade + резервное копирование и
восстановление на синтетических данных. До этого пометка «Stable» запрещена.

## Перед передачей пользователю

- Уже можно **проверить функции** текущей APK как QA на копии экспорта.
- Не обещать обновление `preview51` поверх другой preview51 без проверки сертификата.
- Выполнить **реальный** QA на телефоне: кружки, floating, навигация,
  поиск и крупные архивы. Для найденных багов записывать точные шаги.
- После получения постоянного ключа сделать повторную сборку и тест upgrade.
- Приватные медиа и реальные чаты никогда не коммитить в Public репозиторий.
