# Telegram Archive 0.51 QA — проверка на реальном Android

> Этот файл — **план тестирования**, а не отчёт о пройденных на телефоне тестах.
> Пользовательские архивы и снимки реальных переписок НЕ отправлять в public GitHub.
> QA-пакет `org.openarchive.telegram.qa.preview51` установлен рядом с
> основной версией; он не заменяет существующую 0.50.

## Перед установкой

1. Проверьте, что скачан APK именно из **успешного** Android compile workflow
   рабочей ветки `qa/v052-duplicate-id-safety-20261026`. В архиве Actions
   нужна `app-compactQa.apk`, а НЕ `androidTest` APK.
2. Оставьте существующую 0.50 установленной, не удаляйте приложение и данные.
3. Для первой проверки используйте небольшой *копийный/тестовый* экспорт,
   а не единственный экземпляр личного архива.
4. QA работает офлайн, папка экспорта только читается. Доступность
   медиа зависит от того, присутствуют ли оригинальные файлы в экспорте.

## Основной маршрут обычного пользователя

- [ ] **A01** Запустить приложение: «Мои переписки» и меню доступны, нет зависания.
- [ ] **A02** Выбрать папку с Telegram HTML экспортом; увидеть сообщения по порядку.
- [ ] **A03** Закрыть приложение, открыть снова: текущая переписка и позиция чтения сохраняются.
- [ ] **A04** Найти обычную фразу: переход ведёт к правильному сообщению, оно видно.
- [ ] **A05** Нажать «Ответ на…»: переход ведёт к исходному сообщению,
      не переключает посторонний закреп.
- [ ] **A06** Добавить два закрепа: при переходе из поиска выбранный закреп
      не меняется; стрелка у закрепа меняет его явно.
- [ ] **M01** Открыть видеокружок из чата, нажать ещё раз: пауза и продолжение.
- [ ] **M02** Перемотать кружок ползунком; два сообщения с одинаковым
      MP4 не должны управлять воспроизведением друг друга.
- [ ] **M03** Открыть кружок полностью, поставить на паузу, перемотать
      на другую секунду: видео остаётся на нужном моменте.
- [ ] **M04** Прокрутить чат во время воспроизведения кружка: нет чёрного
      экрана, бесконечного ожидания или самопроизвольного выключения управления.
- [ ] **M05** Воспроизвести OGG/Opus голосовое: пауза, повторный запуск,
      перемотка, звук без запуска чужого приложения.
- [ ] **M06** Открыть голосовое в медиатеке: тот же встроенный плеер.
- [ ] **M07** Открыть фото и GIF: фото отображается, а GIF анимируется;
      GIF не должен попадать в обычное видео.
- [ ] **M08** Убрать оригинальный медиафайл из *копии* экспорта:
      приложение сообщает об отсутствии, не зависает в состоянии «играет».
- [ ] **M09** Проверить медиа с символами #, ? и пробелом в имени файла
      (при наличии таких примеров).
- [ ] **S01** Повторить A01–M07 после сворачивания и возврата;
      нет внезапного сброса и краша.
- [ ] **V01** Годовая и почасовая статистика: все подписи и числовые значения читаются.
- [ ] **V02** Тепловая карта, календарь и сравнение участников: нет
      обрезанных элементов, непонятных цветов и лишней горизонтальной прокрутки.

## Как сообщить об ошибке

Запиши **номер пункта**, что нажал, что ожидал и что случилось.
Например: `M02 — два кружка с одним MP4 — нажал ползунок второго,
перемотался первый — Android 17`.

Для визуальных ошибок можно прислать скриншот или короткий экранный
ролик **в личный чат**, желательно с демонстрационными данными.
Не загружай личные переписки и медиа в публичный репозиторий.
