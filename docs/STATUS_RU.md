# Состояние разработки Telegram Archive Viewer

- Исходная Android-кодовая база: QA 0.47 Reliability UX.
- Не интегрированы все более новые разработки поиска и ответов из параллельной линии работы. Переносить их выборочно, без потери функций и тестов.
- В репозитории есть модульные и инструментальные Android-тесты, а также синтетические ресурсы.
- Полная независимая сборка APK, устройство и регрессионные испытания для опубликованного кода ещё не подтверждены.
- GitHub Actions workflow пока намеренно отсутствуют; перед их созданием проверить безопасность зависимостей, разрешений, секретов и артефактов.
- Для новых веток не заимствовать Git-историю и приватные материалы из других проектов.
- Вопрос лицензий исходников и бинарных учебных ресурсов должен быть проверен отдельно перед распространением продукта.

Нельзя передавать личные Telegram-переписки, записи экрана, фотографии, токены и другие пользовательские данные через CI, issues, коммиты или релизы.
