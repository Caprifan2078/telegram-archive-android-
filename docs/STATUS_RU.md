# Состояние разработки Telegram Archive Viewer

- Основная Android-кодовая база: QA 0.47 Reliability UX.
- Экспериментальная 0.51 сохранена отдельно в ветке `qa/v051-integrated-reliability`; она имеет известные ошибки и не объединена с `main`.
- В проекте есть модульные и инструментальные Android-тесты и синтетические учебные ресурсы.
- Независимая сборка APK, проверка на устройстве и полная регрессия всё ещё не подтверждены.
- Workflow `.github/workflows/public-android-qa.yml` запускает стандартный GitHub-hosted runner **только если репозиторий Public**. Пока Private, задания пропускаются, чтобы не расходовать платные минуты.
- На Public можно запустить workflow вручную в Actions или автоматически при push в main. Он собирает только QA APK (не релиз); перед распространением требуются реальные тесты.
- Для CI не требуются секреты, Telegram-сессии, личные переписки, записи экрана или пользовательские файлы.
- Сохранять новую чистую историю Git; не заимствовать прежние коммиты или приватные материалы.
- Лицензии исходников и бинарных учебных ресурсов отдельно проверить до широкого распространения.

Визуально проверены справочные и учебные статичные иллюстрации; для звука/видео проверены типовые контейнерные метаданные, но это **не** полный визуально-акустический или независимый аудит.

Никогда не отправлять настоящие Telegram-архивы, токены, ключи или пользовательские данные через GitHub Actions, issues, коммиты и релизы.
