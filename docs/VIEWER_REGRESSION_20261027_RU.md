XLSX не пересчитывает формулы, а даты могут быть показаны числами; предупреждение добавлено в интерфейс. Точный внешний вид Office, бинарные DOC/XLS/PPT, имена и порядок всех листов/слайдов, защищённые RAR5 и полный набор 7z ещё не подтверждены. Список архива сейчас плоский: отдельная навигация по каталогам ещё не реализована.

На момент записи статусы Android для новых исправлений не подтверждены. Исторический успех компиляции или прежнего CI не является подтверждением нового коммита.
