# Прозрачный счётчик QA-00

Основа — существующие 11 блоков NAV-01…NAV-11 из `docs/qa/modules/QA-00_REPORT_RU.md`. Для повторяемого минимального счёта блок получает 1 балл только если сценарий из списка целиком проверен в описанных условиях; частичный охват — 0 баллов до завершения блока. Блоки разной сложности, поэтому число **не является** долей трудозатрат или гарантией качества приложения. Здесь учитывается только Android 11 и конкретные синтетические конфигурации, а не все устройства и версии. 100% в этом счётчике не равны автоматическому закрытию QA-00 по полной матрице.
