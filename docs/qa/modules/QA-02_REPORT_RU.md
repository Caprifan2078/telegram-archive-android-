# QA-02 — Чтение переписки: изоляция позиции между чатами

**Дата:** 02.11.2026. **Исходная основа:** `qa/work-modular-audit-00-18`, commit `ac53ee3640de14a4aacced950e5ff146da80614d`. **Рабочая ветка:** `qa/qa02-reading-position-isolation-20261102`. `main` не трогать.

## Проверяемая гипотеза (не считать багом до RED)
При переключении между двумя чатами `lastVisibleMessage` и `lastVisibleTop` являются полями `MainActivity`, а `saveReadingProgress()` при отсутствии видимого сообщения может записать прежний `lastVisibleMessage` в `read_id_<новый чат>`. Это нарушает изоляцию позиции чтения. При последующем открытии другого архива приложению может быть предложено восстановить чужую позицию.

## Реальный синтетический сценарий
1. Создать **только в тестовой установке** две записи реестра `QA02 Альфа` и `QA02 Бета`.
2. Загрузить одно синтетическое сообщение в Alpha, оставить Beta пустой.
3. Настоящим Android-тапом открыть Alpha и увидеть `QA02_ALPHA_ONLY`.
4. Системной Back вернуться на домашний экран; убедиться, что `read_id_Alpha` записан и положителен.
5. Настоящим тапом открыть Beta, убедиться, что отображается «В этой переписке пока нет сообщений.».
6. Системной Back вернуться и проверить, что ключ `read_id_Beta` вообще не создан, а `read_id_Alpha` не изменился.
7. Пересоздать Activity и снова открыть пустую Beta без ложного восстановления.

**Изоляция:** уникальные случайные ключи баз, отдельные SQLite БД и временный реестр. Исходные значения SharedPreferences восстановить, тестовые БД удалить. Никаких приватных сообщений в GitHub и CI.

## Инварианты исправления
- При переходе на другой архив сбрасывать только временный in-memory указатель `lastVisibleMessage`/`lastVisibleTop`, но **не удалять** сохранённые закладки и позиции других чатов.
- Сохранять ID позиции только если сообщение действительно обнаружено среди видимых карточек текущего архива; не копировать старое значение из поля Activity.
- Стандартный Back, повторное открытие, пересоздание Activity, поиск/анализ, закрепы и медиа не должны регрессировать.
- Проверять на Android 11 emulator; физическое устройство не заявлять проверенным.
