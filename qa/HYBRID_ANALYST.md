# Hybrid analyst QA

Experimental AI build explicitly uses JDK 21 (LiteRT-LM 0.10.2 classes are Java 21). Lightweight builds remain Java 17 and have no INTERNET permission. The opt-in model build uses INTERNET solely for user-confirmed download of one pinned public Qwen3-0.6B file, with HTTPS host restrictions, size and SHA-256 checks, private atomic replacement and cancellation; no question or message is included in requests. Source and license: https://huggingface.co/litert-community/Qwen3-0.6B/commit/dd97997951bb15a2a71f539ba17f604707c0b11a (Apache 2.0). Model filters are not claimed to be absent. Full behavior scan streams all message rows, counts six lexical signal groups and retains bounded excerpts; it is not a comprehensive semantic model pass, psychological diagnosis or verdict. LLM receives limited evidence and may misinterpret it. Native inference is not verified until real compatible weights are tested.
