# Experimental deep chat analysis

Opt-in build: gradle assembleProtectedArchiveQa -PqaLocalModel=true. Native runtime pinned to LiteRT-LM 0.10.2 (Apache 2.0 upstream). Compatible .litertlm weights must be supplied by the user separately; no model downloaded or bundled. CPU backend; start with a small instruction-tuned model, subject to device support. No INTERNET permission, private no-backup model file, no persisted prompts, no remote calls. The separate activity runs in a separate process, queries the selected database read-only, sends bounded lexical/synonym hits plus neighboring messages and author counts to a fresh conversation. This is retrieval-augmented inference, not comprehensive full-chat semantic indexing or model training. Generated claims remain unverified. No real-model execution is claimed until physical device test with actual compatible weights. Source: https://github.com/google-ai-edge/LiteRT-LM/tree/v0.10.2
